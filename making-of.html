Wie ich mein 3D-Studio gebaut habe

Mein Portfolio ist kein Video und kein fertiges 3D-Modell. Jedes Möbelstück, jedes Licht und jede Skyline entsteht live im Browser aus Code. Hier zeige ich, wie das funktioniert.

Die Idee

Ein Portfolio, durch das man gehen kann

Die meisten Portfolios sehen gleich aus: Hero, Über mich, Projekte, Kontakt. Ich wollte, dass Besucher meine Arbeit erleben. Deshalb ist meine Website ein nächtliches Design-Studio. Man scrollt durch den Gang, ein Monitor dreht sich zu einem, und auf dem Bildschirm läuft meine echte Website.

Wichtig war mir dabei: Die klassische Website bleibt bestehen. Das Studio ist eine Bühne für sie, kein Ersatz.

01 · Die Szene

Alles aus Code, nichts heruntergeladen

Die Szene ist mit Three.js gebaut. Statt schwerer 3D-Modelle setze ich alles aus einfachen Grundformen zusammen: Schreibtische aus Quadern, Lampenschirme aus offenen Zylindern, das Logo als extrudierte 2D-Form.

Auch die Texturen sind Code. Die Skylines von New York, Berlin und Paris, die Holzmaserung, die Tapete mit dem MI-Muster und die Poster werden beim Laden auf ein unsichtbares <canvas> gezeichnet und dann als Textur verwendet. So bleibt das ganze Studio unter 100 KB eigenem Code.

Wiederholte Objekte wie Deckenlatten, Spots und Bücher zeichne ich als InstancedMesh: Hunderte gleiche Objekte, aber nur ein Aufruf an die Grafikkarte.

02 · Die Bildschirme

Meine Website auf einem 3D-Monitor

Auf jedem Monitor läuft meine echte Website in einem iframe. Damit jeder Monitor nur einen Abschnitt zeigt, bekommt die Seite einen Parameter, zum Beispiel website.html?mi=about. Ein kleines Skript, bridge.js, blendet dann alles andere aus, schaltet ein dunkles Farbschema ein und passt den Abschnitt in den Bildschirm ein.

Studio und Website sprechen über postMessage miteinander. Klickt man auf dem Bildschirm auf „Kontakt“, fährt die Kamera zum Kontakt-Monitor.

Das schwierigste Problem: Zuerst nutzte ich den CSS3DRenderer von Three.js. Optisch funktionierte das, aber in Chrome kamen Klicks auf den Bildschirmen nicht an: Links waren nicht anklickbar. Die Lösung war, jeden Bildschirm selbst auf die vier projizierten Ecken des 3D-Monitors abzubilden, mit einer einzigen flachen matrix3d-Transformation (einer Homographie).
// Bildet ein w×h-Rechteck auf ein beliebiges Viereck q ab (Heckbert)
function homography(q, w, h){
  const [x0,y0] = q[0], [x1,y1] = q[1], [x2,y2] = q[2], [x3,y3] = q[3];
  const dx1 = x1-x2, dx2 = x3-x2, dx3 = x0-x1+x2-x3;
  const dy1 = y1-y2, dy2 = y3-y2, dy3 = y0-y1+y2-y3;
  const det = dx1*dy2 - dx2*dy1;
  const g = (dx3*dy2 - dx2*dy3) / det, k = (dx1*dy3 - dx3*dy1) / det;
  const a = x1-x0+g*x1, b = x3-x0+k*x3, d = y1-y0+g*y1, e = y3-y0+k*y3;
  return `matrix3d(${a/w},${d/w},0,${g/w},${b/h},${e/h},0,${k/h},0,0,1,0,${x0},${y0},0,1)`;
}

Steht die Kamera direkt vor einem Monitor, schalte ich in einen „scharfen“ Modus: Die Website wird dann ohne 3D-Verzerrung in echter Pixelgröße gezeigt. Dadurch bleibt die Schrift gestochen scharf.

03 · Kamera & Bewegung

Scrollen wird zu Gehen

Die Seite besteht unsichtbar aus Abschnitten. Jeder Monitor hat einen Bereich, in dem die Kamera „parkt“. Dazwischen wird die Scroll-Position in eine Fahrt durch den Gang übersetzt. Für eine ruhige Bewegung nutze ich eine Smootherstep-Kurve: Die Kamera fährt sanft an und kommt sanft an.

Die automatische Tour nutzt dieselbe Logik: Sie springt von Monitor zu Monitor und wartet an jedem ein paar Sekunden.

04 · Licht & Material

Warmes Licht ohne teure Lichtquellen

Echte Lichtquellen kosten viel Leistung. Die warmen Lichtkegel unter den Pendelleuchten sind deshalb weiche Verlaufs-Texturen mit additiver Überblendung. Echtes Licht gibt es nur dort, wo es zählt, zum Beispiel am aktiven Arbeitsplatz.

Der Spiegelboden und der große Wandspiegel nutzen einen Reflector, der die Szene ein zweites Mal aus gespiegelter Sicht rendert. Ein Bloom-Effekt lässt Logo, Lampen und Bildschirme leicht leuchten. Im Abend-Modus werden die Skylines neu gezeichnet und Licht und Nebel umgefärbt.

05 · Performance

Schnell, auch auf dem Handy

  • Die Website-Abschnitte laden erst, wenn man sich dem Monitor nähert.
  • Bildschirme, die man gerade nicht ansieht, drosseln ihre Animationen.
  • Auf Handys entfallen der Spiegelboden und die Lichtkegel, und die Auflösung ist begrenzt.
  • Alles, was mehrfach vorkommt, wird als Instanz gezeichnet.
06 · Für alle zugänglich

Barrierefreiheit und Datenschutz

  • Steuerung auch per Tastatur: Pfeiltasten wechseln den Monitor.
  • Wer im System „Bewegung reduzieren“ eingestellt hat, bekommt ruhige Übergänge ohne Animationen.
  • Es gibt jederzeit eine klassische Ansicht ohne 3D.
  • Schriften, Icons und Three.js liegen auf meinem eigenen Server. Beim Besuch werden keine Daten an Google oder andere Dienste übertragen.
  • Die Klänge werden im Browser erzeugt und starten nur, wenn man den Ton einschaltet.
