Corporate Webdesign

Tech Startup Landing Page

Das Redesign einer B2B-Start-up-Website: weniger Fachchinesisch, mehr klare Geschichte, damit Besucher verstehen, was das Produkt löst, und anfragen.

RolleWebdesign & Umsetzung
ArtRedesign-Konzept
Zeitraum✏️ z. B. 3 Wochen
ToolsFigma, HTML/CSS, JavaScript
Ausgangslage

Worum es ging

B2B-Websites erklären oft Funktionen, bevor sie das Problem erklären. Besucher verstehen dann nicht, warum das Produkt für sie wichtig ist. ✏️ Kontext ergänzen: echtes Start-up oder Übung?

Ziel war eine Seite, die in wenigen Sekunden klar macht: Was ist das, für wen ist es, und was ist der nächste Schritt?

Ziele

Was die Lösung können sollte

  • Storytelling: Problem → Lösung → Beweis → Anfrage.
  • Interaktive Elemente, die das Produkt zeigen statt beschreiben.
  • Responsives Layout und ein klarer Call-to-Action.
Prozess

So bin ich vorgegangen

  1. 01

    Analyse

    Die alte Seite durchgegangen: Wo steigen Besucher aus, welche Texte sind unklar? ✏️ Deine wichtigsten Beobachtungen

    Ergebnis: Schwachstellen
  2. 02

    Botschaft

    Die Kernbotschaft in einem Satz formuliert und die Seite um diese Geschichte herum aufgebaut.

    Ergebnis: Story & Struktur
  3. 03

    Design

    Hero, Feature-Bereiche und Kundenlogos als Komponenten gestaltet, mit einem auffälligen, aber ruhigen CTA.

    Ergebnis: Desktop & Mobile Design
  4. 04

    Umsetzung

    Die Seite responsiv in HTML, CSS und JavaScript gebaut, mit kleinen Animationen beim Scrollen.

    Ergebnis: Live-Seite
Einblicke

Aus dem Projekt

Ergebnis

Was dabei herauskam

Eine Landing Page, die mit einer klaren Geschichte statt mit Funktionslisten arbeitet. ✏️ Ergebnis ergänzen; nur echte Zahlen nennen, z. B. aus einem Test mit 5 Personen

Learnings

Was ich mitnehme

  • Die beste Überschrift beschreibt das Problem des Kunden, nicht das Produkt.
  • Ein einziger klarer Call-to-Action wirkt stärker als drei verschiedene.
  • ✏️ eigene Erkenntnis ergänzen
